# 收敛数据库基础层

## Description

统一数据库连接、事务、迁移、分页和批量写入能力，同时保持每个业务模块对自身表和写入规则的所有权。

## Acceptance Criteria

- [ ] 公共层提供连接、事务、分页、批量插入、批量更新和冲突处理能力。
- [ ] 公共层不提供绕过业务 Service 的通用外部写接口。
- [ ] 每张现有业务表能够映射到唯一所属模块。
- [ ] 批量写入支持明确的整体回滚或部分成功语义。
- [ ] 金额和价格继续使用精确数值类型。
- [ ] 相关数据库测试和迁移检查通过。
