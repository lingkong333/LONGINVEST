# 建立简化 Cron 定时器

## Description

在普通后台中运行 Cron 计划，负责实时行情、17:00 当日日线和必要维护计划，不再运行独立调度进程。

## Acceptance Criteria

- [ ] Cron 使用数据库交易日历和 Asia/Shanghai 时间。
- [ ] 相同计划和计划时间只能创建一个业务任务。
- [ ] 服务重启不会重复创建已经存在的计划任务。
- [ ] 错过实时窗口的任务记录为错过，不进行无期限补跑。
- [ ] 17:00 当日日线每个交易日最多创建一个自动批次。
- [ ] 管理员可以查看计划、最近执行和下次执行时间。
- [ ] 定时、重复创建和重启场景测试通过。
