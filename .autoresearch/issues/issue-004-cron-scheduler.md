# 建立双路径定时基础

## Description

在普通后台中建立两类定时能力：盘中 `HH:mm` 使用进程内定时注册，17:00 日线和维护计划使用可恢复 Cron。该事项只建设定时基础，不实现具体行情抓取。

## Acceptance Criteria

- [ ] 两类定时均使用数据库交易日历和 Asia/Shanghai 时间。
- [ ] 后台启动和配置变化时刷新未来盘中时间点，不每 10 秒轮询数据库。
- [ ] 盘中触发不创建任务、发生记录或行情批次，停机错过后不补跑。
- [ ] 相同 17:00 或维护计划只能创建一个持久业务任务。
- [ ] 服务重启不会重复创建已经存在的持久计划任务。
- [ ] 17:00 当日日线每个交易日最多创建一个自动批次。
- [ ] 管理员可以查看当前计划、后台状态和下次时间。
- [ ] 配置刷新、准时触发、错过、重复创建和重启场景测试通过。
