# 实现数据源请求预算

## Description

为所有数据源提供统一的每日额度、最小请求间隔、并发和优先级保护，确保自动、手动、重试和探测请求不会突破上游限制。

## Acceptance Criteria

- [x] 每个实际上游和具体能力支持每日上限、重置时区、最小间隔和最大并发配置。
- [x] 支持数据源总额度和具体数据能力额度。
- [x] 请求发出即计数，失败或超时不退回额度。
- [x] 配置每日 50000 次后，第 50001 次请求在本地被阻止。
- [x] 并发请求和服务重启不能造成额度超卖或清零。
- [x] 实时行情和当日日线可以保留优先额度，历史回填不能占用；盘中行情无需先创建任务即可领取额度。
- [x] API 返回已用、剩余、重置时间和最近限流原因。
- [x] 正常、并发、重启、额度耗尽和重置测试通过。
