# 重构多数据源路由

## Description

按股票清单、实时行情、当日日线、历史未复权、历史前复权和因子能力分别配置主源与备用源，并准确追踪 AKShare 背后的实际上游。

## Acceptance Criteria

- [ ] 每种数据能力可以独立配置主源、备用源和是否自动切换。
- [ ] 来源身份包含适配器、实际上游、具体接口、能力和算法版本。
- [ ] 东方财富、新浪、Tushare Pro 和 BaoStock 能力未探测通过前不能用于正式路由。
- [ ] 主源整体连接失败、限流或额度耗尽时按配置切换备用源。
- [ ] 主源部分缺失时只向备用源请求缺失范围。
- [ ] 每条正式数据保存完整来源身份和采集时间。
- [ ] 同一股票同日来源冲突进入质量检查，不静默覆盖。
- [ ] 前复权来源或算法变化时要求完整窗口重建，禁止跨算法补片。
- [ ] 凭据只通过安全引用读取，接口和日志不回显明文。
- [ ] 管理员固定数据源时仍受该数据源请求预算约束。
- [ ] 自动切换、手动固定、部分补缺和冲突测试通过。
