# 重构多数据源路由

## Description

按股票清单、实时行情、当日日线、历史日线和复权能力分别配置主源与备用源，并执行受控切换和来源追踪。

## Acceptance Criteria

- [ ] 每种数据能力可以独立配置主源、备用源和是否自动切换。
- [ ] 主源整体连接失败、限流或额度耗尽时按配置切换备用源。
- [ ] 主源部分缺失时只向备用源请求缺失范围。
- [ ] 每条正式数据保存真实来源和采集时间。
- [ ] 同一股票同日来源冲突进入质量检查，不静默覆盖。
- [ ] 管理员固定数据源时仍受该数据源请求预算约束。
- [ ] 自动切换、手动固定、部分补缺和冲突测试通过。
