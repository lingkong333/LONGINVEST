# 重构全市场当日日线

## Description

将全市场当日日线改为一个业务任务。数据源适配器根据真实接口能力选择分页、分组或单股请求，任务内部保存检查点并批量写入。

## Acceptance Criteria

- [ ] 一个交易日只创建一个全市场当日日线业务任务。
- [ ] 不为每只股票创建独立业务任务记录。
- [ ] 任务启动前显示采集方式、预计请求数、额度需求和预计时间。
- [ ] 支持分页、批量股票和仅单股三类采集计划。
- [ ] 任务内部保存可恢复的分组检查点。
- [ ] 行情逐股校验，数据库按批写入，只重试缺失或失败股票。
- [ ] 页面显示总数、成功、缺失、失败、来源和当前阶段。
- [ ] 单股失败不会回滚其他有效日线。
- [ ] 后台启动自动扫描停机期间缺失交易日，合并为一个恢复任务并按日期补齐。
- [ ] 使用代表性全市场数据完成服务器性能验收。
