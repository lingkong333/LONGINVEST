# 实现并验证四类数据源适配器

## Description

实现东方财富、新浪、Tushare Pro 和 BaoStock 适配器，并在服务器验证每个上游的实际能力、权限和数据口径。本事项不负责历史任务或盘中信号流程。

## Acceptance Criteria

- [ ] 四类上游均实现能力探测和统一数据契约；无权限能力明确显示不可用。
- [ ] AKShare 调用记录其实际东方财富或新浪上游，不能保存为独立来源。
- [ ] 实时、当日日线、历史未复权、历史前复权和因子能力分别验证。
- [ ] 所有外部请求经过统一预算、超时、有限重试、熔断和安全错误转换。
- [ ] Tushare 与 BaoStock 凭据使用安全引用，测试、日志和接口不泄露。
- [ ] 每个上游都有正常、空数据、字段变化、超时和限流的离线契约测试。
- [ ] 每个拟启用能力完成服务器小范围真实验收，并记录耗时、覆盖和复权口径。
