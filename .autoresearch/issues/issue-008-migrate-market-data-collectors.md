# 迁移实时行情、历史 K 线和复权采集

## Description

将现有实时行情、历史 K 线和复权获取统一接入新的数据获取模块、请求预算和多数据源路由。

## Acceptance Criteria

- [ ] 实时行情、历史未复权、历史前复权分别使用明确的数据能力契约。
- [ ] 所有外部请求经过统一请求预算。
- [ ] 历史回填不会消耗实时行情和当日日线的保留额度。
- [ ] 手动与自动切换使用相同数据源路由。
- [ ] 历史任务支持进度、暂停、继续、取消和只重试失败范围。
- [ ] 已保存历史行情和前复权版本保持可查询。
- [ ] 相关模块测试和真实数据源小范围验收通过。
