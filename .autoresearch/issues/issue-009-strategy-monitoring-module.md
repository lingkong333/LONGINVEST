# 整理策略与监控模块

## Description

统一策略草稿、发布版本、参数、四档目标、监视分组、唯一订阅和持仓，并使用按需隔离容器执行策略代码。盘中实时信号链由 Issue #13 接入。

## Acceptance Criteria

- [ ] 策略支持草稿、验证、发布和回滚。
- [ ] 发布版本不可修改，并绑定代码和参数哈希。
- [ ] 所有策略参数使用统一 Schema 校验。
- [ ] 所有策略输出四档有序目标价格和诊断摘要。
- [ ] 订阅绑定调度、目标、策略、滞回、通知策略和当前启停版本。
- [ ] 策略代码在无网络、无数据库凭据的按需容器中执行。
- [ ] 隔离容器完成、失败或超时后被销毁。
- [ ] 版本、参数、隔离、目标、订阅和持仓测试通过。
