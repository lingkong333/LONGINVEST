# 整理策略与监控模块

## Description

统一策略草稿、发布版本、参数、四档目标输出、监视列表和真实行情信号，并使用按需隔离容器执行策略代码。

## Acceptance Criteria

- [ ] 策略支持草稿、验证、发布和回滚。
- [ ] 发布版本不可修改，并绑定代码和参数哈希。
- [ ] 所有策略参数使用统一 Schema 校验。
- [ ] 所有策略输出四档有序目标价格和诊断摘要。
- [ ] 只有已发布策略和真实行情能够产生正式信号。
- [ ] 策略代码在无网络、无数据库凭据的按需容器中执行。
- [ ] 隔离容器完成、失败或超时后被销毁。
- [ ] 版本、参数、隔离、目标和信号测试通过。
