# 重构回测和候选确认流程

## Description

回测使用训练期计算目标、测试期模拟表现，并根据指标形成候选股票。候选股票只有经过管理员确认才进入监视中心。

## Acceptance Criteria

- [ ] 训练期只用于计算目标价格，测试期不重新训练目标。
- [ ] 结果展示收益、最大回撤、交易次数和失败原因。
- [ ] 候选筛选方案可以命名、保存、启停和复用。
- [ ] 创建任务时可覆盖本次阈值，最终方案版本、规则和阈值冻结到任务快照。
- [ ] 候选股票支持单只和批量确认。
- [ ] 未确认候选不能进入监视中心。
- [ ] 回测不能修改正式目标、正式信号或发送正式通知。
- [ ] 接口提供任务进度、候选列表和确认结果，页面由 Issue #15 接入。
- [ ] 后端关键流程和恢复测试通过。
