# 重构回测和候选确认流程

## Description

回测使用训练期计算目标、测试期模拟表现，并根据指标形成候选股票。候选股票只有经过管理员确认才进入监视中心。

## Acceptance Criteria

- [ ] 训练期只用于计算目标价格，测试期不重新训练目标。
- [ ] 结果展示收益、最大回撤、交易次数和失败原因。
- [ ] 候选条件可以按回测指标配置并保存在任务快照中。
- [ ] 候选股票支持单只和批量确认。
- [ ] 未确认候选不能进入监视中心。
- [ ] 回测不能修改正式目标、正式信号或发送正式通知。
- [ ] 页面显示任务进度、候选列表和确认结果。
- [ ] 后端、前端和浏览器关键流程验证通过。
