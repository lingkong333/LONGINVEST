# 建立统一通知模块

## Description

建立统一通知入口，第一版对接邮件和企业微信。业务模块只提交通知意图，通知模块负责渠道、模板、发送记录和有限重试；飞书保留扩展接口但不在本事项实现。

## Acceptance Criteria

- [ ] 调用方只需提交通知类型、业务对象、模板参数和幂等键。
- [ ] 邮件和企业微信分别通过适配器实现，飞书不作为完成条件。
- [ ] 单渠道失败不影响其他渠道或原业务提交。
- [ ] 相同幂等键不会产生重复正式通知。
- [ ] 每次发送尝试、结果和安全错误摘要可查询。
- [ ] 通知失败只执行配置允许的有限重试。
- [ ] 接口支持查看渠道状态、投递和尝试记录，页面由 Issue #15 接入。
- [ ] 后端正常、重复、单渠道失败、超时和恢复测试通过。
