# 建立统一通知模块

## Description

建立统一通知入口，并对接邮件、企业微信和飞书。业务模块只提交通知意图，通知模块负责渠道、模板、发送记录和有限重试。

## Acceptance Criteria

- [ ] 调用方只需提交通知类型、业务对象、模板参数和幂等键。
- [ ] 邮件、企业微信和飞书分别通过适配器实现。
- [ ] 单渠道失败不影响其他渠道或原业务提交。
- [ ] 相同幂等键不会产生重复正式通知。
- [ ] 每次发送尝试、结果和安全错误摘要可查询。
- [ ] 通知失败只执行配置允许的有限重试。
- [ ] 页面支持查看渠道状态、投递和尝试记录。
- [ ] 后端、前端和浏览器关键流程验证通过。
