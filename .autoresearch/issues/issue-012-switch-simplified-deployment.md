# 切换简化部署并移除旧设施

## Description

在所有模块完成迁移后切换到前端、API、普通后台和 PostgreSQL 四个常驻组件，移除 Redis/RQ 和旧后台角色，并完成最终数据与性能验收。

## Acceptance Criteria

- [ ] 切换前停止旧体系创建新任务，并处理所有未完成旧任务。
- [ ] 已完成任务历史、管理员和正式业务数据完整保留。
- [ ] 常驻组件只有前端、API、普通后台和 PostgreSQL。
- [ ] 策略隔离容器只在任务执行期间存在。
- [ ] Redis/RQ、分发器、看门狗、维护进程和监督器不再运行。
- [ ] 空闲状态常驻容器总内存不超过 800 MiB。
- [ ] 全市场当日日线期间常驻容器总内存不超过 1.2 GiB。
- [ ] 数据库迁移、完整测试、前端构建和容器验收通过。
- [ ] 服务器关键入口、任务恢复、数据采集、回测和通知冒烟检查通过。
- [ ] 回退步骤经过演练或可验证检查。
