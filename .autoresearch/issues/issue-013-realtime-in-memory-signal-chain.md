# 建立盘中内存行情与信号链

## Description

按管理员配置的时间点或立即检查，在普通后台内完成监控股行情集合、主备补缺、质量判断、信号计算和通知提交。原始实时行情不入库，也不创建通用任务或批次表。

## Acceptance Criteria

- [ ] 启动和配置变化后，进程内定时器只注册未来的 `HH:mm` 时间点。
- [ ] 触发时读取当前交易日历、启用订阅和目标，不创建 `job`、发生记录或行情批次。
- [ ] 主源后只对缺失股票请求备用源，全部终态或 30 秒截止后才开始信号判断。
- [ ] 缺失、过期、冲突和迟到行情不改变状态，也不使用上一轮价格。
- [ ] 原始行情和响应不入库；正式判断只保存价格、时间、来源、目标版本和状态变化等最小证据。
- [ ] 信号提交前再次校验当前订阅和目标版本，暂停或过期输入被跳过。
- [ ] 合格信号与通知事件、渠道投递在同一事务提交。
- [ ] 正常、19/20 部分成功、超时、暂停竞态、目标变化、重复触发和进程重启测试通过。
