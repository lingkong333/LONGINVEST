# 建立历史自动补全与前复权版本

## Description

历史采集由系统自动计算每只股票的完整范围和缺口，支持停机恢复、双口径保存和前复权版本原子切换，不要求普通用户填写日期。

## Acceptance Criteria

- [ ] 开始日取可信上市日期，缺失时使用市场安全起点；结束日取最近已完成交易日。
- [ ] 按交易日历和现有覆盖合并连续缺口，普通完整模式不要求输入日期。
- [ ] 指定日期范围仅作为高级修复和诊断入口。
- [ ] 未复权按缺失日期幂等批量写入，冲突进入质量流程。
- [ ] 前复权版本冻结来源、接口、算法、窗口、锚点和哈希；来源或算法变化时重建完整窗口。
- [ ] 全市场永久保存未复权、当前有效前复权和版本历史，并能原子保留旧版本。
- [ ] 任务支持进度、暂停、继续、取消、检查点和只重试失败范围。
- [ ] 后台启动自动扫描停机缺口并合并恢复；正常、断档、重复、部分失败、重启和算法切换测试通过。
