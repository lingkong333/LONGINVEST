# 统一接入完整功能页面

## Description

在后端模块稳定后统一完成中文管理页面和正式接口接入，复用 shadcn/ui 基础组件，并保持现有主题、菜单和页面偏好。

## Acceptance Criteria

- [ ] 登录、仪表盘、股票列表/详情、历史采集、监视中心、策略与目标、回测、信号、通知、数据源、质量、任务、告警、审计、日历和设置页面均接正式 API。
- [ ] 股票详情展示可调日期范围的日线图、开盘/收盘价格及可精细调整的支撑线和压力线。
- [ ] 历史页面默认不要求日期，展示自动范围、断档、来源、双口径进度和任务控制。
- [ ] 回测页面支持筛选方案复用、本次覆盖、候选单只或批量确认。
- [ ] 盘中页面不展示不存在的实时任务或原始行情历史，只展示最近检查和最小信号证据。
- [ ] 通知页面第一版只配置邮件与企业微信，飞书不显示为可用渠道。
- [ ] 所有表单覆盖加载、空数据、失败、重复提交、权限和冲突状态。
- [ ] 前端类型检查、相关测试、生产构建及桌面和移动端浏览器关键流程通过。
