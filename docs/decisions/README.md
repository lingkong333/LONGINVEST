# 设计偏差记录

只有实现候选方案与当前需求基线不一致时才创建记录，文件名使用 `YYYY-MM-DD-模块-主题.md`。

每份记录至少包含：

- 生效规格版本和章节
- 涉及模块
- 文档要求
- 当前实现或候选方案
- 两种方案在正确性、安全性、可靠性、复杂度、兼容性和可测试性上的优缺点
- 最终决定及原因
- 需要先更新的规格版本
- 代码、数据迁移和测试影响
- 实际验证结果

当前已接受的设计决定：

- `2026-07-28-简化单机架构.md`：将多队列、多常驻后台角色收敛为 PostgreSQL 任务和一个普通后台进程，并定义数据迁移与回退边界。
- `2026-07-29-功能流程与运行时边界.md`：确认盘中行情使用进程内定时器和内存批次，长任务继续持久恢复，并固化多数据源、历史补全、通知与回测边界。
- `2026-08-04-回测-全市场筛选与多时段价格版本.md`：将全市场逐股筛选归入策略模块，以不可变候选批次连接回测，并支持有序多时段和按日生效的四档价格版本。
- `2026-08-04-策略与回测日期职责拆分.md`：策略筛选只接收训练区间并冻结四档价格，创建回测时再独立提供回测区间。
- `2026-08-04-行情-全市场快照独立于监控订阅.md`：盘中按配置时间抓取全市场内存快照，监控订阅只消费快照；自动与手动执行统一保存摘要。
- `2026-08-06-通知对象与信号绑定.md`：把全局渠道目标拆为可复用通知对象，由信号选择具体接收方并按对象记录投递。
