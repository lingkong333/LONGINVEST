# V4.5 策略训练与回测时间边界及监控执行状态

本版本继承 V4.4 的全部内容，仅以下差异覆盖旧规则。

## 1. 策略筛选

策略筛选的日期输入只包含训练开始日和训练结束日。系统把冻结的前复权日线作为训练数据传给已发布策略；策略只判断股票是否符合条件，并为符合条件的股票输出强支撑、弱支撑、弱压力、强压力四个价格。筛选阶段不得要求、读取或保存未来回测区间。

多组训练区间按顺序编号，各组开始日和结束日只能保持不变或向后移动。筛选结果冻结训练数据、策略版本、参数、四档价格和诊断信息。

## 2. 候选批次回测

创建回测时，用户为筛选批次中的每个训练区间单独填写回测开始日和回测结束日。回测开始日必须晚于对应训练结束日；多组回测区间的开始日和结束日只能保持不变或向后移动，区间之间允许交叉。

回测阶段只显示和编辑回测时间，不重新填写训练时间，不重新调用策略。回测直接使用筛选批次冻结的四档价格和候选股票，对指定回测区间的历史日线执行交易模拟。

## 3. 监控列表

监控列表顶部必须展示总体监控状态和当天日内快照执行状态。当天每个配置时间至少展示：计划时间、是否执行、执行状态、计划股票数、成功抓取数、失败数、开始时间、完成时间和耗时。尚未到达的计划显示“待执行”，已到时间但没有执行证据的计划显示“未执行”。

盘中监控时间配置放在监控股票列表之后。页面状态直接使用调度发生记录和行情批次作为执行证据，不用前端推测成功。

## 4. 验收

1. 策略筛选页面只出现训练时间，仍能输出候选股票和四档价格。
2. 创建回测时只填写回测时间，且不能早于对应训练结束日。
3. 监控列表顶部可看到当天所有配置时间及其真实执行结果。
4. 盘中监控时间配置位于页面下方。
5. 旧筛选批次可查询；创建新回测时统一由新请求提供回测区间。
