# V4.6 全市场快照与批量日线采集

本版本继承 V4.5 的全部内容，仅以下差异覆盖旧规则。

## 1. 全市场每日日线

每个交易日收盘后，全市场未复权日线必须优先使用支持分页、整日截面或多股票批量查询的数据源。一次上游请求必须承载一组股票或一个市场分页，不得把全市场正常采集拆成数千次单股请求。

批量请求失败时按数据源配置决定是否切换到下一批量数据源。只有批量阶段成功后仍缺少的少量股票允许逐股补抓；缺失数量超过 200 时不得进入逐股补抓，任务应快速结束并保留批次失败原因。正常全市场采集目标为三分钟内完成。

## 2. 盘中全市场快照

盘中快照是全市场行情数据的固定时间截面，不依赖监控订阅是否存在。交易日到达任一已配置时间时，系统先按每组最多 100 只股票并发抓取全市场快照，再仅对已有监控订阅执行策略判断和信号处理。

盘中原始行情批次保持在内存中，不永久保存全市场原始快照明细。系统必须持久保存每次执行摘要，包括触发方式、状态、计划股票数、成功数、失败数、开始时间、完成时间、耗时和错误码。

## 3. 手动触发

监控列表顶部提供“手动抓取快照”操作。手动执行与自动执行使用相同的全市场抓取流程和执行摘要；手动记录必须出现在当天执行列表中，并明确标记为手动触发。相同幂等键不得重复执行。

## 4. 验收

1. 全市场日线不再因批量失败转为数千次逐股请求。
2. 真实全市场日线采集在可用数据源下三分钟内结束，并展示成功数、失败数和耗时。
3. 没有任何监控订阅时，交易日配置时间仍会执行全市场快照。
4. 手动触发完成后，页面当天执行列表立即出现对应记录。
5. 自动和手动执行均可看到触发方式、状态、数量、开始时间、完成时间和耗时。
