# 需求基线

当前唯一生效的需求与技术基线：

- `A股个股长波段价格提醒系统_需求与技术设计_v4.7_通知对象与信号绑定.md`

V4.6、V4.5、V4.4、V4.3、V4.2、V4.1、V4.0、用户提供的 V3.0 原文和已经完成施工所依据的 V3.1 至 V3.15 均保留为不可改的历史版本。V2.1 和旧设计摘要也不能作为独立需求来源。

实现与当前基线不一致时，必须先记录对比结论：

1. 文档方案更好：按文档修改实现和测试。
2. 新方案更好：先发布新的规格版本并把本文件指向新版本，再修改实现和测试。
3. 不允许代码先行后长期补文档，也不允许在模块内部静默偏离公共契约。
